# Ativos tipográficos não distribuídos

Os nove arquivos binários de fontes não integram este pacote. O código-fonte e os CSS originais foram preservados, inclusive as referências em `app/src/brand/tokens.css`. Para fidelidade visual, adquirir/recuperar legitimamente os ativos tipográficos e sua licença, colocando-os em `app/public/fonts/`, ou ajustar o design system com revisão e QA antes do deploy. Não atribuir mudança visual à ausência de código da aplicação.
